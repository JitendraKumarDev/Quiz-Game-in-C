# Quiz Game in C

A simple and interactive Quiz Game developed using C Programming.

## Features
- Multiple Choice Questions
- Four options for each question
- User answer input
- Correct and wrong answer checking
- Automatic score calculation
- Final percentage display

## Technologies Used
- C Programming
- VS Code
- GCC Compiler

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Compile the program:

```bash
gcc quiz.c -o quiz.exe
```

4. Run the program:

```bash
.\quiz.exe
```
