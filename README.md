# 🎯 Quiz Game in C

A simple and interactive **Quiz Game developed using C Programming**. This project allows users to answer multiple-choice questions, check their answers, and calculate their final score and percentage.

## 📌 About the Project

This is a beginner-friendly C programming project created to practice fundamental programming concepts such as variables, conditional statements, user input, and mathematical operations.

The game displays multiple-choice questions and evaluates the user's answers automatically.

## ✨ Features

- Multiple-choice questions (MCQs)
- Four options for each question
- User-friendly console interface
- Automatic answer checking
- Correct and incorrect answer messages
- Real-time score calculation
- Final score and percentage display

## 🛠️ Technologies Used

- **Language:** C Programming
- **IDE:** Visual Studio Code
- **Compiler:** GCC
- **Operating System:** Windows

## 🚀 How to Run the Project

Follow these steps to run the program on your computer.

**1. Clone the Repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Open the Project Folder**

```bash
cd Quiz-Game-in-C
```

**3. Compile the C Program**

```bash
gcc quiz.c -o quiz.exe
```

**4. Run the Program**

```bash
.\quiz.exe
```
