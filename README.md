# Quiz Game in C

A simple and interactive Quiz Game developed using C Programming.

## Features
- Multiple Choice Questions
- Four options for each question
- User answer input
- Correct and wrong answer checking
- Automatic score calculation
- Final percentage display

## Technologies Used
- C Programming
- VS Code
- GCC Compiler
